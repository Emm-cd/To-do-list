Descripción del Proyecto: 
Es una aplicación web de lista de tareas que permite gestionarlas, mostrando tres estados posibles de las actividades. 

Instrucciones de Uso: 
1. Para registrar actividades se escriben mediante el formulario de color azul, para agregarla al board se da click en "Agregar".  
2. Cada actividad se agrega por default en el listado de "Pendientes" identificado por el color rojo. En donde se mostrara el texto ingresado previamente junto con dos botones ("Iniciar" y un icono de un bote de basura). Para cambiar de estado una actividad se da click en "Iniciar" lo que la movera al listado de "En Proceso" identificado por el color amarillo, en caso de haber cometido un error en el registro de la actividad y querer borrarla se da click en el segundo ícono. 
3. Una vez que nuestra actividad este en proceso, nos aparecer un botón con el ícono de una palomita, el cual al dar click nos permitira indicar que nuestra actividad ha sido completada, teniendo como resultado nuestra actividad ahora en el listado de "Realizadas".
4. Considerando la cantidad de las actividades registradas se tiene un ícono para eliminar en caso de no requerir más la tarea finalizada.  
5. Para cada lista se visualiza un contador de las actividades que se encuentran en ese momento. 

Tecnologías Utilizadas:
1. HTML5 - Para la interfaz
2. CSS3 - Estilos
3. JavaScript - Lógica
